FVRemote

FVRemote は、ゲーム「ファイティングバイパーズ」の対戦台の配信を自動化するための、個人用のソフトです。運営者が自分の PC だけで使います。

このソフトがすること

  • 運営者自身の YouTube チャンネルに、配信の予定(日付入りのタイトル・概要欄・サムネイル)を YouTube Data API で作ります。
  • 作った配信の予定を、運営者のいつものストリームキーに結び付けます。

運営者以外の人の Google アカウントやデータは扱いません。

About (English)

FVRemote is a personal tool used only by its operator. It uses the YouTube Data API to schedule live broadcasts (title, description, thumbnail) on the operator's own YouTube channel and binds them to the operator's stream key. It does not access any other user's data.
