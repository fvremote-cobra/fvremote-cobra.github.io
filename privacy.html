FVRemote プライバシーポリシー

最終更新日:2026年10月10日

1. 使う情報

FVRemote は、運営者が Google アカウントでログインしたときに、YouTube Data API を通じて、運営者自身の YouTube チャンネルの配信の予定とストリームの情報を読み書きします。

2. 使い方

配信の予定を作ること、ストリームキーに結び付けること、動画の情報(カテゴリ・タグ・言語・サムネイル)を設定することにだけ使います。

3. 保存と共有

ログインの情報(トークン)は運営者の PC の中にだけ保存し、外部のサーバーには送りません。情報を第三者に提供・販売することはありません。

4. 取り消し

アクセスの許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

FVRemote による Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー(限定的な使用の要件を含む)に従います。

Privacy Policy (English)

FVRemote accesses the operator's own YouTube channel through the YouTube Data API only to create and configure scheduled live broadcasts. OAuth tokens are stored only on the operator's PC and are never sent to any other server or shared with third parties. Access can be revoked at any time from the Google Account permissions page. FVRemote's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
